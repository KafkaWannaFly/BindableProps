# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

To report a vulnerability, please open an issue on [GitHub Issues](https://github.com/KafkaWannaFly/BindableProps/issues).

## Dependency Scanning

Dependabot monitors dependencies for both .NET (nuget) and npm (DocumentSite) ecosystems. GitHub Actions workflows are also scanned.
